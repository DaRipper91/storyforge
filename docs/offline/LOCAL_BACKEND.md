# LocalBackend (Step D2a)

In-process GDScript replacement for the FastAPI app's CORE routes. The client rewire (PythonClient -> LocalBackend)
is NOT part of this step. Contract: `docs/offline/CLIENT_BACKEND_CONTRACT.md`; frozen behaviour:
`tests/golden/routes/*.json` (`tests/golden/ROUTES_README.md`).

## Files

| File | Role |
|---|---|
| `godot/scripts/backend/game_backend.gd` | `GameBackend` (RefCounted): `signal state_changed(state)`, `request(method, path, body, query) -> {status, body}`, `is_ready()`, `get_state()` |
| `godot/scripts/backend/local_backend.gd` | `LocalBackend extends GameBackend`: route table, handlers, persistence |
| `godot/scripts/backend/request_schema.gd` | `RequestSchema`: pydantic-v2/FastAPI 422 body emulation (type/loc/msg/input/ctx) |
| `godot/scripts/core/data/seed_campaign_data.gd` | GENERATED by `tools/golden/gen_gd_seed.py`; `SeedCampaignData.get_state()` = deep copy of the seed |
| `godot/tests/golden/run_routes.gd`, `golden_compare.gd`, `route_divergences.json` | route replay runner, shared numeric-tolerant compare, allowlist (`[]`) |
| `tools/golden/run_gd_routes.sh` | the only engine entry point for the route runner |

Constructor: `LocalBackend.new(save_dir = "user://campaigns/", clock = Callable(), rolls = null, seed_state = {}, mtime_provider = Callable())`.
`clock` returns an ISO-8601 UTC string (default: system time, no microseconds); `rolls` is a `CoreRollProvider`
(default live; `set_roll_provider()` swaps it, the test scripts one per step); `seed_state` replaces the bundled seed
(used for the boot state and for `campaigns/new`); `mtime_provider(dir_name, state_path) -> float` feeds `last_modified`.

## Response convention

`{"status": int, "body": Variant}`. Same strings as HTTP: error bodies are `{"detail": ...}`; 422 `detail` is a list.
FastAPI's 500 page is returned as the plain String `"Internal Server Error"` (the contract sketch proposed
`{"__text__": ...}`; a String is closer to the real text/plain body). The client shim must `JSON.stringify` only
non-String bodies.

`state_changed(state)` fires (deep copy of the FULL state, only if someone is connected) after any request that
committed, including requests that then answer 500 (generic interact), `time/sync` when it changed an NPC target,
and `campaigns/new|load` (no bus event in Python, but the live state was swapped so the UI should refresh).

## Persistence layout

`<save_dir>/<campaign_dir>/state.json` (default `user://campaigns/`). The boot campaign is `family_campaign_01`: on
construction it is loaded from disk if present, else the seed is used (nothing is written until the first commit,
like `main.lifespan`). Written from the state manager hooks: `commit_hook` (after the revision bump) and
`snapshot_hook` (`append_narration`, saves without a bump). `time/sync` never saves. Write = `.state-<usec>.tmp` in
the same directory, flush, rename over the target (remove + rename fallback where rename does not overwrite).
No fsync is available from GDScript. Keys are written in insertion order (not sorted) because `characters` order is
observable (creation order drives `names`, `transformed_ids`, travel spawn order). **Number normalization**: Godot
parses every JSON number as float, so integral floats are converted to ints on save, on load, on seed load and on
request bodies (5.0 -> 5); non-integral floats are untouched.

`campaigns/new`: id `campaign_YYYYMMDD_HHMMSS` from the injected clock (UTC; Python used naive local time), saved
immediately (revision unchanged), becomes the live campaign. `campaigns/load`: id resolved under the base dir;
absolute ids, `\`, drive prefixes, `.`, `..` escapes -> 400; missing `state.json` -> 404; nested `a/b` ids are allowed
(as in Python). `GET /api/campaigns` lists top-level dirs with a `state.json`, sorted by `mtime_provider` descending
(ties: dir name ascending); unreadable files are skipped.

## Error-status conventions (copied from the Python routes)

- Validation first: pydantic-shaped 422 before any handler logic (`RequestSchema`).
- `StateError`/`ValueError` from the core map per route: join 409, leave 404, update_name/save_draft/set_phase/create 400,
  start 409, attack 400. Any other core error (unknown actor in grid/interact_entity, `KeyError` on non-move grid
  diffs) is an unhandled Python exception -> 500 `"Internal Server Error"`.
- The generic `interact` (empty floor / live enemy cell) commits and then 500s (`diff["from"]` KeyError in the except
  fallback). Faithful parity, flagged as a Python bug in the contract doc.
- No cookies offline: `controller_id` always comes from the body; missing -> 401.

## Intentionally stubbed

- `/api/npc/**` (ENCOUNTER, any method): 503 `{"detail":"Not available offline yet"}`.
- `POST /api/action/freeform` (AI): 501 `{"detail":"Freeform actions need the AI narrator, which is not available offline"}`.
- `POST /api/auth/desktop_login`: 200 `{"status":"ok","user":{"sub":"offline","email":"offline@localhost","name":"Offline Player","picture":"","offline":true}}`
  (Python returns the JWT payload minus nothing; no `exp`/cookie here). Other `/api/auth/*`: 404.
- Plain `move` narration: always the built-in fallback `"<name> moves to (x, y)."` (the Gemini narrator does not exist offline).

## Known divergences / notes

`godot/tests/golden/route_divergences.json` is `[]`: all 141 recorded steps match. Unrecorded differences:
no websocket; `state_changed` also fires for `campaigns/new|load`; new-campaign id uses the injected (UTC) clock;
exotic pydantic coercions beyond numeric-string and bool -> int are not replicated; loading an old save does not
re-run model validation (defaults are not back-filled); `last_modified` real mtimes are whole seconds;
`time/sync` with a negative schedule coordinate answers 500 (pydantic `Coord` error in Python).

## How to run

    bash tools/golden/run_gd_routes.sh                 # all flows; exit 0 only on RESULT: OK
    bash tools/golden/run_gd_routes.sh --flow=campaigns --verbose
    GD_ROUTES_DIR=/path/to/copy bash tools/golden/run_gd_routes.sh   # negative testing on a corrupted fixture copy
    bash tools/golden/run_gd_tests.sh                  # function-level fixtures (unchanged)
    uv run python tools/golden/gen_gd_seed.py          # regenerate the seed const (deterministic)

The runner copies `godot/` to a scratch dir (never runs godot in the worktree), replays each flow against a fresh
`LocalBackend` with a temp save dir, a frozen clock (`2026-01-01T12:00:00+00:00`), frozen mtimes
(`1700000000 + index` over sorted campaign dirs) and the step's scripted RNG; it checks status, body, the trimmed
`state_after`, exact RNG values and bounds, and that `state_changed` fired iff the app published bus events.
