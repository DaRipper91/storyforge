## 2026-06-23 - Use Object Pooling for Konva Canvas Particles
**Learning:** Continuously creating and destroying `Konva` node objects for ambient visual effects (like particles) causes memory churn and Garbarge Collection pauses. Furthermore, adding custom properties directly to external library objects causes V8 to de-optimize their hidden classes, leading to further performance degradation.
**Action:** Use an object pool to reuse `Konva` nodes by simply `hide()` and `show()`ing them, and track custom variables in separate standard JavaScript wrapper objects instead of modifying the third-party objects directly.
